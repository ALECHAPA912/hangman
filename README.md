# Hangman Game

Hangman is a guessing game for two or more players. One player thinks of a word, phrase, or sentence and the other(s) tries to guess it by suggesting letters or numbers within a certain number of guesses. Originally a paper-and-pencil game, there are also electronic versions (like this one).

In this case you can play and save your game if you want. I used serialization for that feature.
